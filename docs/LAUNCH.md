## Lead with the visual

Open on the grid of 991 files. Put the number in the first frame. Click **Clean the demo project** and let the grid disappear. Keep the protected items visible throughout. Finish with **Undo cleanup** and the grid refilling.

For a short clip, use two seconds for the before shot, three for cleanup, two for what stayed, and three for undo. Use “synthetic, verified CLI run” in the caption.

## English post

My coding agent finished the feature and left me the cleanup.

I built LeftoverKit for the scripts, screenshots, data exports, old reports and spare worktrees that come with AI coding. This demo clears 991 files and one merged worktree with one command. It leaves the source, .env, final delivery and a live log where they are.

Then I undo it. All 991 files come back.

Try the visual demo, then run `leftoverkit clean` in a Git project.
